# 📚 Entendendo Algoritmos — Estudos e Prática

Repositório criado para **treinar, praticar e acompanhar meu aprendizado de algoritmos**, seguindo o livro *"Entendendo Algoritmos" (Grokking Algorithms)*, de **Aditya Y. Bhargava**.

A ideia aqui não é só copiar os exemplos do livro, mas realmente **entender** cada algoritmo, implementá-lo com as próprias mãos, testar variações e anotar o raciocínio por trás de cada solução.

## 📖 Sobre o livro

**Entendendo Algoritmos**, de Aditya Y. Bhargava, é uma introdução visual e amigável aos algoritmos mais comuns em ciência da computação, cobrindo temas como busca binária, ordenação, recursão, grafos, programação dinâmica e muito mais — com ilustrações e exemplos práticos que facilitam o entendimento.
