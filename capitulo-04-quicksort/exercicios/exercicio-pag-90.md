# Qaunto etempo levaria, em notação Big O, para completare cada uma dessas operações:

## 4.5 Imprimir o valor de cada elemento em um array.
### R: 
\(O(n)\) — percorre todos os elementos uma vez.

## 4.6 Duplicar o valor de cada elemento em um array.
### R: 
\(O(n)\) — percorre todos os elementos uma vez e multiplica cada um por 2. Não é \(O(n^2)\), pois não há um laço dentro de outro.

## 4.7 Duplicar o valor apenas do primeiro elemento do array.
### R: 
\(O(1)\) — realiza uma operação, independentemente do tamanho do array.

## 4.8 Criar uma tabela de multiplicação com todos os elementos do array.
### R: 
\(O(n^2)\) — para cada elemento do array, multiplica todos os elementos por ele. Isso envolve dois laços, cada um percorrendo \(n\) elementos.
