# **Algoritmos Gulosos**

São simples de escrever e normalmente chegam perto da solução perfeita.

> "Muito bom" é bom o suficiente.

São úteis para encontrar soluções aproximadas para problemas difíceis de resolver, como alguns problemas NP-completos.

- [Algoritmo de Dijkstra](../../capitulo-07-algoritmo-de-dijkstra/anotacoes/Algoritmo-Dijkstra.md)

## **Problemas NP-completos**

São problemas para os quais não se conhece um algoritmo eficiente capaz de encontrar a solução ótima em tempo razoável.

- Podem exigir um tempo de execução muito alto conforme o tamanho da entrada aumenta.
- Algoritmos gulosos podem ser usados para encontrar soluções aproximadas.
- Exemplo: Problema do Caixeiro-Viajante.
